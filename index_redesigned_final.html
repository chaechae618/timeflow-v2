Step 5 — 모델 평가: Naive 기준선과 비교해 각 모델의 가치를 판단합니다.
• MASE < 1: Naive보다 우수 (이 조건 불충족 시 해당 모델은 폐기)
• SMAPE: 10% 이하 우수 / 20% 이하 양호 / 20% 초과 미흡
• TS: |TS| ≤ 4이면 편향 없음 / 초과시 편향 의심
• AutoARIMA가 선택한 (p,d,q) 파라미터와 AIC를 함께 표시합니다.

STL 분해 (Seasonal-Trend decomposition using Loess):
• 트렌드 강도 > 0.5: 뚜렷한 장기 방향성 → ETS, STL 유효
• 계절성 강도 > 0.5: 규칙적 주기 패턴 → 계절성 모델 필수
• 잔차 ACF: CI 안에 있으면 백색잡음 → 모델이 패턴을 완전히 설명함
